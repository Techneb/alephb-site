About AlephB

AlephB is a product data analyst who also teaches SQL and Python. On the side I build small apps, each meant to do one useful thing. This site lists the projects and publishes long articles on how they were built: the methods, the numbers, the trade-offs and the mistakes.

The projects

  • Compromise is a free iPhone app for groups who want to meet up. You and your friends each enter a starting point and how you travel (on foot, by public transport, by bike or by car), and it suggests bars, cafés, restaurants and some thirty other kinds of place that everyone reaches in about the same number of minutes. It covers more than 350 cities and can show which terraces will still be in the sun when you arrive. There is no account and no advertising, and the addresses stay on the phone.
  • The Ritz Affair is a detective game set in Paris in 1912 that you play by writing SQL in your browser. It has twelve chapters, and each one introduces a new piece of the language that you need to find the next clue. I wrote it for my own SQL course. Students play alone or as teams on a live class leaderboard. It is free, and you can play without an account.
  • The Clerk's Handbook goes with the game: plain-English lessons on SQL from SELECT and WHERE to joins, GROUP BY and CASE, with examples you can run on the page and graded exercises with solutions. You can use it without playing the game.
  • What's my size? is a Chrome extension, not released yet, that recommends your size at a brand by comparing the garment with clothes you already own and know fit you. It finds those clothes in your order emails and keeps your wardrobe in a Google Sheet that belongs to you, with no AlephB account.

How the work is done

When an app needs personal information, such as a home address or an order history, I keep it on your device or in a file you own. Some features do need a server, for example sharing a group link or keeping a class leaderboard, and each project's privacy policy says what that server stores and for how long.

Each project has its own automated test suite, run before every release. The game goes further: each build regenerates its database and checks that every puzzle still returns its answer and that the obvious wrong queries still fail.

Compromise's places and buildings come largely from OpenStreetMap (© OpenStreetMap contributors, ODbL) and other open datasets, and the articles name the sources they rely on. The game and the handbook came out of a classroom, and anyone can use them for free in a course or at home.

The articles

The articles describe how the projects work from the inside: how travel time is turned into a fair ranking, how a worldwide places dataset is built from OpenStreetMap on a small budget, how to tell whether a terrace is in the sun, how clothing sizes can be read from order emails without the emails leaving your computer, and what teaching SQL with a story has shown so far. Every number in them comes from the projects' own notes, tests and measurements. When I don't know something, I leave it out.

The articles about The Ritz Affair never give away a clue, an answer or a shortcut through a chapter. The game only works if the reader has to write the query.

This site

alephb.uk is a set of plain HTML pages with no build step, served by GitHub Pages. Visits are counted with Cloudflare Web Analytics, which sets no cookies and doesn't follow individual visitors. The site may show Google ads, and the privacy page explains how those ads work and how to refuse personalised ones.
